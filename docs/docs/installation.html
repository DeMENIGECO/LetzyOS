Installazione

Requisiti di sistema

Prima di installare LetzyOS, assicurati che il tuo sistema soddisfi i seguenti requisiti minimi:

  • RAM: 2 GB o superiore (4 GB+ consigliati)
  • Spazio su disco: 4 GB o superiore
  • Processore: 4 GHz o superiore (8 GHz+ consigliati)
  • GPU: opzionale, LetzyOS funziona tramite terminale

Procedura di installazione

Vai alla pagina di download e scarica il file compresso per il tuo sistema operativo. Se richiesto, estrailo e segui le istruzioni indicate nell'avvertenza ⚠️.

⬇️ Vai alla pagina di download

Avvio del sistema

Per avviare LetzyOS, apri il terminale nella cartella del file eseguibile e digita:

./letzyos
