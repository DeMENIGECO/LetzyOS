Utilità per percorsi

Ls: visualizzare il contenuto di una directory

Il comando ls viene utilizzato per visualizzare i file presenti nella directory corrente. 

ls

Make: creare un file

Il comando make viene utilizzato per creare un nuovo file. Devi specificare il nome del file. 

make esempio.txt

Write: scrivere su un file

Il comando write permette di scrivere del contenuto all'interno di un file esistente. 

write esempio.txt Ciao LetzyOS!

Delete: eliminare un file

Il comando delete viene utilizzato per eliminare un file esistente. Devi specificare il nome del file. 

delete esempio.txt

Stamp: visualizzare il contenuto di un file

Il comando stamp permette di visualizzare il contenuto di un file. 

stamp esempio.txt
