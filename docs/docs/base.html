Comandi di base

Echo: lavorare con l'output

Il comando echo viene utilizzato per visualizzare un messaggio sul terminale. Ad esempio, digitando echo Ciao, mondo! verrà visualizzato il messaggio sul terminale.

Help: ottenere informazioni sui comandi

Il comando help mostra la lista dei comandi disponibili in LetzyOS, insieme a una breve descrizione.

Exit: uscire dal sistema

Il comando exit viene utilizzato per uscire da LetzyOS. Il comando chiude la sessione corrente e restituisce il controllo al sistema operativo sottostante.
