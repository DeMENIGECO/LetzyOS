Compilazione

📝 Nota

Se vuoi semplicemente iniziare a usare LetzyOS, puoi saltare questa pagina.

Requisiti

Per poter compilare LetzyOS, è necessario avere installato sul proprio sistema i seguenti strumenti:

  • Python 3.9 o superiore
  • pip
  • Codice sorgente di LetzyOS scaricato

Installazione delle dipendenze

Per compilare LetzyOS, installa le dipendenze necessarie utilizzando pip:

pip install pyinstaller colorama

Compilazione del sistema operativo

Una volta installate le dipendenze, puoi procedere con la compilazione di LetzyOS:

pyinstaller main.py --name="letzyos"
